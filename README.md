# WINE EDITOR 🍷 — v1.1.1
A free browser-based photo editor by Vilor.

## v1.1.1
- Preserved the existing visual theme and color palette.
- Improved mobile editing: the preview remains pinned while scrolling through controls.
- Increased touch target size for sliders and tool buttons.
- Replaced emoji UI decoration with consistent inline SVG icons.
- Kept all existing filters and editing features.

## Run
Open `index.html` in a modern browser. No build step or dependencies required.

## Publish on GitHub Pages
1. Create a public repository named `wine-editor`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.

## Included
- Upload local images
- Working brightness, contrast, saturation, grayscale and blur adjustments
- Preset filters
- Rotate and flip
- Text overlay and simple frames
- Undo/redo and reset
- Download edited image as PNG

Image processing runs locally in the browser. AI background removal, object removal and upscaling need a secure processing service or model integration and are not included yet.
